One word for the whole internet: **feral**. Not a library, not a town square — a wild animal loose in everyone's pocket, unmoderated, unpredictable, funny, and impossible to house-train.

> feral

## How it works

`main.py` (Python 3 standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 30 characters of UTF-8 text, exactly one word, and not only whitespace.

```sh
python3 main.py
```
